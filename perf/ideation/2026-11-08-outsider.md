## Framing numbers I use throughout

- Decode at 256k: 42 ms = 28 ms host wait + ~14 ms GPU-own (serialized per layer today).
- Host-served bytes: 90 × 9.5 MB = 855 MB per token. Both the DMA path and the CPU pool read those bytes out of the same host DRAM (~50 GB/s), so the host tier's hard floor is 855 MB / 50 GB/s = **17 ms** (or ~12 ms for the 64 RAM-tier records, plus NVMe device time 7 × 1.36 = 9.5 ms unless hidden). Today's 28 ms is ~11 ms above that floor; nothing that only hides latency can go below the floor, only fewer misses, fewer bytes or faster DRAM can.
- Prefill: 3.5 ms/row × 8192 = 28.7 s per chunk. Bus floor: 140 GB / 50 GB/s = 2.8 s per chunk (0.34 ms/row). Compute floor at ~40 TFLOPS achieved f32: ~0.6 GFLOP/row = 0.015 ms/row. The chunk is 10x above its bus floor and ~200x above its compute floor, so neither bus nor FLOPs is the limiter.
